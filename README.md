# Overview

This project started out with MUCH bigger hopes and dreams than I thought. I had a feeling I was going to be able to accomplish everything I wanted to when it came to making a simple game but boy was I so wrong. 
I wanted to biuld a lowkey game full of levels, saves, enemies, loot and progression. What I ended up with was a glorified scratch game. It needs lots and lots of work and frankly I have so miuch more respect for AAA game devs now. 


This is the code for a simple game. You start as a character and have to navigate your way around 'The Bunker'. It is very much a work in progress and a labor of love but one that I intend to keep working on.

I wrote this as a way to try a new software (Godot) and to try and see if this was something that I would want to try and do later on down the road in a professional sphere and I can say now that I will pass on most video game developemnt as a whole unless its for a pspecific assion project.

# Development Environment

This game was written all using Godot and GDScript.I know that you can use C# in Godot and I was very much tempted to do so but I figured that if I was going to use Godot that I might as well try my hand at learning and using GDScript
I used alot of ChatGPT this time around as I couldnt quite get Claude to cooperate with me in the ways that I needed it to.
